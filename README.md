# delivery_process_design

## 📌 Executive Summary
This Business Process Management (BPM) project re-engineers the International Door-to-Door Delivery process for DHL Express Vietnam. By applying Value-Added Analysis and root-cause analysis tools, the project identifies operational bottlenecks and proposes an automated document validation workflow to enhance service reliability.

## 🛠️ Tech Stack & Tools
- **BPM Notation:** BPMN 2.0
- **Modeling Tool:** bpmn.io

## 📂 Project Structure
├── process-maps/       # AS-IS and TO-BE BPMN 2.0 diagrams (.bpmn, .png)
└── README.md           # Project documentation

## 💼 Business Impact & Recommendations
- **Cost Reduction:** Automated Pre-Customs Document Validation reduces manual handling costs from **$40.125 to an estimated $34–$36** per shipment.
- **Implementation:** Transition from manual document checking to automated pre-clearance validation.
